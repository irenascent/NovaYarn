# NovaYarn

NovaYarn provides a distributed, Load-Balancing framework for real-time data processing, built on a Fault-Tolerant, auto-scaling library.

NovaYarn is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- NovaYarn provides a distributed, Load-Balancing

- built on a Fault-Tolerant, auto-scaling

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/NovaYarn.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

NovaYarn is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
